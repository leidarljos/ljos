The cloud seat guard that `ljos cloud up` installs now reads each `git push` and `gh` command's arguments instead of matching the command text. It refuses every push that would update a `cursor/*` branch or tag, including `+cursor/x`, `refs/tags/cursor/x`, a bare push or `HEAD` from a `cursor/` checkout, and `--all` or `--mirror` with a local `cursor/` branch, and it refuses `gh pr create`, `gh pr new` and `gh pr merge` with `-R` or `--repo` before the verb. Pushing a `cursor/` branch onto another branch, a remote URL or option value that contains `cursor/`, and gh comment text that mentions `pr merge` are no longer refused.
