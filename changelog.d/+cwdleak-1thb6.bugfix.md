An absolute root reached through a symlink into the start directory is walked on the deadline, and a stat that does not answer is not left for this thread.
An absolute `PATH` entry, the sibling `ljos-hud`, and `LJOS_HUD_BIN` are stated on that deadline. A stat outside the start directory that does not answer is skipped.
A relative `PATH` entry is left for the parked directory. A HUD program is a regular file.
`ISSUE_ROOT`, when it is set, is the only root walked. `LJOS_HUD_BIN` keeps the bytes it was given; the launcher still trims the path it execs.
