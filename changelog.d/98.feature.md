`ljos persona NAME --retire` withdraws a persona, so it leaves the roster and casts no more ballots. Only the conversation that defined it may retire it; `--replace` retires one another seat or conversation defined, as it takes over a name on a define. Before, a persona could only be overwritten, never removed. `ljos persona NAME --view TEXT --check` says what the define would do and writes nothing: whether the name is free, this seat's, or another seat's and so refused, and which live personas already hold the same view or speak to the same domains. Two agents on one seat built overlapping panels, such as `rust-perf` and `rust-idiom`, and the check names the overlap before the second is written.
