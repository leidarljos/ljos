The protocol, the seat skill, the MCP reference, the environment reference and the ljos-mcp instructions and tool descriptions now say which calls claim a ticket: `ljos_start`, `ljos_sitting` and `ljos_claim`, plus `ljos_note` and `ljos_finish` when they retry a claim a sitting left pending, and `ljos_complete` when it claims a node a gone conversation of this seat left.
They also say that `ljos_finish` releases the claim rather than completing the node, that a later sitting hands back an expired claim whose conversation is gone, that no hook files a claim or cites a commit as a deed, that a git commit is only logged as a note, and that Stop, session end, shutdown and idle finish no claim.
