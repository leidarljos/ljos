An absolute `TMPDIR`, `VISSUE_ROOT`, `ISSUE_ROOT`, or `LJOS_HUD_BIN` under the start directory is resolved with the working-directory deadline before the process parks.
A tracker root whose final component is not there yet is the resolved parent plus that name, which is the path a create would use.
A parent that does not resolve, or a walk that overruns the deadline, is still an error.
