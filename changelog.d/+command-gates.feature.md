The static guard refuses a commit whose author or committer is not Rohit Goswami <rgoswami@ieee.org>, a commit message that carries a machine trailer, and a commit that omits Signed-off-by when `.ljos/gates.toml` sets `signoff`. A push needs a passing `ljos evidence record` for that exact tip, and a plain push with that record needs no approval. A merge needs green CI on the head sha and every Cursor Bugbot thread resolved or replied to. The hook, a wake, and `ljos guard_check` share that check.
