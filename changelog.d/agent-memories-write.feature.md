An agent's memory is written at once, with no person's approval first. `ljos remember` and the MCP `ljos_remember` under a runner, `ljos finish --lesson`, `ljos findings --remember` and the prompt hook's correction store a live claim with origin `agent-derived`; before, a finish lesson and a correction were proposals that only `ljos accept` from the person made live, and an agent's remember was an episode until a review. Against a pack that still holds agent writes, the held proposal is accepted on the spot. Secrets, the size cap and the two-sentence cap still refuse a write.
Every write's `source` names the seat, the harness, the session, the host, the time (`at`) and the reason: `LJOS_MEMORY_WHY`, or the opening of the person's latest prompt with key-shaped words redacted.
`ljos memories list|review|tui|prune` reviews afterwards. `review` lists unreviewed agent memories newest first with their provenance and asks keep, edit, merge or drop; `--json`, `--keep ID`, `--drop ID`, `--edit ID --text T` and `--merge ID --merge ID [--text T]` script it. `tui` browses them in the terminal, filtered by seat (`s`) or date (`f`), and keeps (`a`), drops (`d`), edits (`e`) or merges marked rows (`m`, `M`). `prune --stale` names duplicates and memories never recalled in `--days` (30), and drops them only with `--apply`. Verdicts are kept in `$XDG_STATE_HOME/ljos/memory-reviews.jsonl`.
