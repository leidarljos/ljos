The seat line `ljos` writes into a ticket's logbook goes to the heading whose own properties drawer has the `:ID:`, not to the first `:ID:` line in the file, which could be quoted in another ticket's body.
A rerun in the same minute writes no second copy, a second note still gets its own line, and `- Claimed by SEAT` is not written while `:CLAIMED_BY:` names another seat.
