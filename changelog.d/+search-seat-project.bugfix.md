`ljos search` prefers tickets in the seat's own project or repo over other projects' tickets: `LJOS_PROJECT`, the checkout's project, `vissue identity`, and the name of the git checkout name the seat's project, along with the projects its facts name and a project the query names.
Another project's ticket comes after those in its group, and one that misses a query word goes to the end of the page.
A word-ranked `ljos search "LTO metatensor link"` on seat amsel-paper had printed nine other repos' tickets that each shared one word with the query.
