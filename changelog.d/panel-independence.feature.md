Ballots and design candidates are bound to the harness session and a per-process nonce, and the signature covers that binding. A second ballot with that session on the same question is refused at cast and ignored in the tally, and a session that filed a candidate cannot vote. A design whose session read another candidate before filing is flagged. `ljos panel run ISSUE` starts each designer and each persona in its own `cursor-agent -p` or `claude -p` session, and a designer is given only the brief.
