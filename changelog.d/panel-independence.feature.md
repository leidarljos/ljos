Ballots and design candidates are bound to the harness session and a per-process nonce, and the signature covers that binding. `ljos consensus` refuses to settle when one session cast more than one ballot, when a session both authored a candidate and voted, or when every ballot traces to one session. A design whose session read another candidate before filing is flagged. `ljos panel run ISSUE` starts each designer and each persona in its own `cursor-agent -p` or `claude -p` session, and a designer is given only the brief.
