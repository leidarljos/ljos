Relative `TMPDIR`, `VISSUE_ROOT`, `ISSUE_ROOT`, and `LJOS_HUD_BIN` are resolved against the start directory once, before the process parks, with the same deadline as the working-directory probe.
A missing component or a path that does not answer in time is an error, and `..` after a symlink follows that symlink's parent, so the start directory is not used in their place.
