The HUD lookup states a candidate once and execs that path.
A second stat used to carry a deadline, so a slow stat of a file the walk had already accepted made `--foreground` exit 127 and `--hide` exit 0.
A mode 644 `ljos-hud` in an empty `PATH` entry is handed to `execvp` as `ljos-hud`, which keeps searching when a later script's interpreter is missing or not executable.
