A slash HUD path is the path that was stated.
`realpath` does not run on the calling thread, so a sibling, a `.` entry, a relative `bin`, or an absolute `PATH` entry in a directory that does not answer is still that program.
A relative path stated in the parked directory is joined to that directory, with `.` and `..` folded in the text, so the move before `exec` names the same file.
