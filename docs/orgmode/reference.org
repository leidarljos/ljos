Each page answers one lookup. [[file:reference-commands.org][Commands]] is the one most readers want. The Model Context Protocol (MCP) server is =ljos-mcp=.

- [[file:reference-commands.org][Commands]]: every ljos verb, the stores it reads and writes, and what it does.
- [[file:reference-mcp.org][MCP tools]]: the tools =ljos-mcp= serves, the core set and how to list every tool.
- [[file:reference-git-hooks.org][Git hooks]]: the global git hooks that book commits, and how to install, remove and check them.
- [[file:reference-environment.org][Environment and sync files]]: the variables the seat reads, a temporary home, and the files ljos sync carries.
- [[file:reference-rules.org][Rules and checks]]: user rules, what a rule reads, the checks ljos keeps for the tracker, and the threat model of the pack token.
- [[file:reference-jev.org][Jev settings]]: the keys of jev.toml and what each one changes.
- [[file:reference-learning.org][The learning rules]]: how trust rows move after an outcome, and the settings that bound them.
- [[file:reference-help.org][Help text]]: what =ljos --help= prints, taken from this version.
