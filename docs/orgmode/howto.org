Each page is one task. Start with the first two; the rest stand alone.

- [[file:howto-runner.org][Connect an agent runner]]: wire ljos into a runner, an editor or a shell-only agent. The page also puts the seat in the status bar.
- [[file:howto-check.org][Check the seat]]: read what ljos doctor prints, which rows fail, and when it exits 1.
- [[file:howto-seats.org][Add a seat and let it close tickets]]: add a seat to the tracker and grant it the right to close named tickets.
- [[file:howto-recall.org][Bring memory into the prompt]]: turn on the prompt hook, ask what a task touches, and read an issue's history as one dated list.
- [[file:howto-memory.org][Keep memory current]]: keep the cards, record a number that is measured again and again, and retire a memory with its reason.
- [[file:howto-mesh.org][Move memory across lanes]]: pull lane exports into a seat and push that seat's memories to the shared handoff.
- [[file:howto-sitting.org][Sit an issue]]: open a sitting, end it with a lesson, and hold a done claim that sits beside a failing test.
- [[file:howto-mail.org][Send mail between seats]]: write to another seat, read the inbox, and wake an idle seat when mail reaches it.
- [[file:howto-handover.org][Hand work to another seat]]: sign a handover bundle and receive from the same sender again.
- [[file:howto-vote.org][Vote and settle a decision]]: cast ballots as seats and personas, settle them, and set or move the trust rows.
- [[file:howto-personas.org][Run personas in panes and subagents]]: open persona panes in another tool and spawn a persona as a subagent.
- [[file:howto-judge.org][Put the judgments to a model]]: turn on Jev, or point the same judgments at a local model or a runner, and cast persona ballots through it.
- [[file:howto-command-check.org][Read the command check]]: what the command check warns on, the rewrite, block-on-warning, and which branches the push check covers.
- [[file:howto-eb-stack.org][Bump a recipe with eb-stack]]: bump an EasyBuild recipe with eb-stack in a sitting, plan a whole generation, and keep what the campaign taught.
