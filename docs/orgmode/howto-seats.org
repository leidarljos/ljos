#+title: Add a seat and let it close tickets
#+description: Add a seat to the tracker and grant it the right to close named tickets.
#+options: toc:nil num:nil

The tracker's =vissue.toml= lists the seats. =ljos seat add NAME= writes the row,
so nobody edits the file by hand. With no list, any seat can write. The first
=seat add= starts the list, and a seat that is not on it cannot write.

Name the seat you are, and add it before any other:

#+begin_src console
$ export LJOS_SEAT=alice
$ ljos seat add alice
$ ljos seat add carol
#+end_src

=ljos seat= prints the name in use. A read with no name set prints =every-seat=.
A write with no name set uses the login name, or a short stable name when that login is missing, and the first write says so.
If you added another seat first, the next line tells you to run =ljos seat add= for your own seat.
That row is how you get back on the list.

By default a seat cannot close a ticket. =ljos finish= leaves the ticket open, and a person closes it.
A grant changes that for one seat. Here a person says in their own words that carol may close
the tickets she filed or has claimed, and alice writes it down. =--via= has to be the seat
this command runs as:

#+begin_src console
$ ljos seat grant carol close=own --quote "carol may close what she files" --at 2026-10-29T02:00:00Z --via alice
#+end_src

The row lives in =vissue.toml=. It holds the quote, the time, the recorder named by =--via= and
the tracker commit. A grant edited into the file by hand is ignored. A seat cannot grant itself.
Every close that uses the grant cites the record.

A seat that holds a ticket notes it with =ljos note "TEXT"= and ends it with =ljos finish --lesson "..."=.
Pass an id to name a different ticket. With no ticket open, both exit 1 and name =ljos sitting ISSUE=.

=ljos release ISSUE= gives one ticket back. The ticket stays open.
Releasing a ticket another seat claimed names that seat and =ljos send=, and releasing an unclaimed ticket names =ljos claim=.
A pile of quiet claims is one command, =ljos release --stale=.
It releases every claim this seat holds that has been quiet longer than the hand-back window (=LJOS_LEASE_SECS=, 900 seconds) and whose conversation is not running on this host.
Another seat's claim stays. The ticket stays open.
=--older-than 2h= sets the window. =--dry-run= prints the count and changes nothing. =--verbose= prints one line per ticket.
