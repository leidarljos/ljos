#+title: Help text
#+description: What the ljos help command prints, taken from this version.
#+options: toc:nil num:nil

=ljos --help= prints the daily set (=search=, =remember=, =file=,
=sitting=, =note=, =finish=, =ready=, =show=, =doctor=) in under 24 lines.
Every other command still runs.
=ljos help --all= lists every command across Start, Daily, Tracker, Memory,
Coordination and Admin.

# BEGIN ljos-sample help
#+begin_src text
$ ljos --version
ljos 0.44.0
$ ljos --help
Memory, a work tracker and a command guard for coding runners

Usage: ljos <COMMAND>

Daily:
  search    Show what ljos remembers about a topic, best match first
  remember  Remember one lesson, stored as written
  file      File a ticket. The new id is the only line on stdout
  sitting   Start work on a ticket, or file a plan and sit it
  note      Note progress on an issue, dated, and commit the tracker
  finish    Finish work on a ticket: remember the lesson, strengthen the memories it used, hand the claim back
  ready     List tickets that are open and not waiting on another open ticket
  show      Show one ticket, or one memory
  doctor    Check that ljos is ready, and print the rows that need action

Options:
  -h, --help     Print help
  -V, --version  Print version

A seat is the name in `LJOS_SEAT`: the person or agent this process acts as.
Start with `ljos doctor` and `ljos onboard`; `ljos protocol` explains the rest.
`ljos help --all` lists every command.
$ ljos doctor --help
Check that ljos is ready, and print the rows that need action.

Exit 1 when a required program, the memory store or its token does not answer, the tool server a runner starts or the cloud signing key does not, the note queue is damaged, or the tracker directory is not writable. A tracker that has not been created yet does not fail this command.

Example: `ljos doctor`

Usage: ljos doctor [OPTIONS]

Options:
      --all
          Print every row, the ones that answer included
          
          [alias: --verbose]

      --fix
          Refresh runner skills and runner env files this ljos wrote, and replace a stale cloud guard rule file. Also create a missing ljos home and config file, move a stale lock or pid file aside, start packsetd with `packset ensure`, and record a runner session seat. A skill edited by hand, an env file ljos did not write, a cloud guard file that is missing or not a known older version, git hooks, runner hooks, policy, credentials and keys are left in place. A stale file is moved aside with a `.bak` suffix

  -h, --help
          Print help (see a summary with '-h')
