# sit

Open one sitting, do the work, close it. One playbook, one occupancy.

## 1. Open

`ljos sitting ISSUE`. Doctor, cards, due, island, this recipe, recall, timeline, claim. Grade each due claim. Occupancy is the claim; this name stays until finish or release.

## 2. Work

Produce deeds, cite them. Remember what will still be true. Prefer a settled choice. A decision with more than one defensible answer is `ljos vote` then `ljos consensus`.

## 3. Close

`ljos finish ISSUE --gen N --lesson "..."`. Completing the claim node does not close the ticket; finish with status done does. A new task is a new sitting.
