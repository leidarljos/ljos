# arena

Designs write scratch. The host writes a rubric on a compose child. Personas vote that compose `--as`, then DeGroot.

## 1. File designs

Each design is a child of the parent ticket, or a scratch file the compose names. Do not vote A/B/C as accept-at-most-one without a compose.

## 2. Rubric on the compose

The host writes a note or body that opens with `rubric:` on the compose issue (or its parent). Brief reprints it.

## 3. Vote the compose

One brief per persona, each ends with `ljos vote ISSUE --for accept|reject --as NAME`. Then `ljos consensus ISSUE`. schema_yes is not GREEN.
