# company-panel

A panel of named personas. Unscoped inbound trust is the floor; `--about` only adds weight.

## 1. Seat the roster

`ljos personas`. Write a missing voter with `ljos persona`. Each write plants an unscoped inbound trust row from the seat at weight 1.0 when none exists.

## 2. Brief

`ljos brief NAME ISSUE`. Each brief carries the playbook body, the five principles, and the rubric. One subagent per persona, one step.

## 3. Ballot then settle

Each member: `ljos vote ISSUE --for OPTION --as NAME`. Then `ljos consensus ISSUE`. Model roles in a recipe are spawn hints; personas still vote `--as`.
